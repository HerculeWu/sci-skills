# The paper's Argument DAG is a JSON file in a schema shared with another project

`build-paper-argument` writes the paper's Argument DAG as `papers/<paper>/argument.json`, validated against `skills/build-paper-argument/schema/argument.schema.json`, and `write-paper` reads it; it was an Obsidian canvas. The canvas was barely usable for viewing and most of its tokens were layout and formatting, which every agent that read the graph paid for. Another project trains a writing model on graphs in exactly this form and copies the schema file verbatim, so its field names, enums and rules are fixed: a field that cannot carry what a skill needs is raised with the user, never adapted in place, and any incompatible change bumps `version`. Viewing moved to a self-contained `viewer.html`. The other skills keep their canvases: only the paper's own graph is shared.
